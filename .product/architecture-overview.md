Tests de bout en bout : `apps/web/e2e/` (Playwright, Chromium) rejoue les parcours utilisateur sur trois appareils (ordinateur, téléphone, tablette) et mesure 36 écrans sur 9 formats (dont douze de Gérer, avec compte et données simulés : sans compte, loyers du mois, tous les loyers, fiche d'un bien, louer, quittance imprimable, ajouter un bien, « J'ai acheté ce bien », mes biens, mes locataires, modifier une location, supprimer un bien), sur le build de production servi par `vite preview`, en local et dans le job CI `e2e` ; voir `architecture/e2e-playwright.md`, `architecture/responsive.md` et `architecture/coque-fixe.md` (menu et en-tête en vue quand le contenu défile).

Partage d'un projet (ADR-009) : lien court `/p/:id` lu par `/api/partage` (copie sans la visite en D1, 90 jours après la dernière ouverture) ; repli `/partage#z=` compressé, sans serveur ; changement de domaine préparé (`@loupe/capture/origines`, page `/transfert`, bascule derrière `DEKLIC_TRANSFERT=1`) ; voir `architecture/liens-courts-domaine.md`.

Application mobile (PWA, ADR-007) : le même site s'installe sur l'écran d'accueil. Un service worker garde la coque et ses fichiers pour l'ouverture hors ligne ; la cible de partage du manifeste ouvre `/projets/nouveau?…` avec l'annonce reçue d'une autre app, servie par la coque en cache pour que le texte ne quitte pas l'appareil ; voir `architecture/responsive.md`.

## Flux de données d'une analyse

Résoudre → Capturer → Extraire → Normaliser → Géocoder → Enrichir → Estimer → Vérifier → Calculer. Le moteur intervient uniquement à l'étape 9 et reçoit un `Projet` validé (schéma Zod) ; il rend des `Resultats` jamais persistés : complets, ou partiels quand le loyer visé manque (`complet: false`, sections qui en dépendent à `null`, `manques` et raison des feux inconnus ; voir `architecture/hypotheses-optionnelles.md`).

Capturer (étapes 1 et 2) : l'extension ou le bouton-favori lit la page ouverte avec les règles de son portail (`@loupe/capture`), encode la capture dans `#capture=…` et ouvre `/projets/nouveau` ; le web décode, valide, pré-remplit Vérifier et efface le fragment. Le fragment n'est jamais envoyé au serveur ; voir `architecture/extension.md`. Lien collé dans Nouveau projet : la page demande à l'extension (script « pont », `window.postMessage`) de lire l'annonce dans un onglet du navigateur de l'utilisateur, puis l'IA complète les trous du texte ; voir `architecture/lecture-auto.md`. Sans extension ou si elle n'ouvre pas l'annonce : le Worker (`POST /lecture`) rapporte la page, le navigateur y applique les mêmes règles dans un document inerte, rien n'est gardé côté serveur ; photos et fiche du bien suivent le projet ; voir `architecture/lecture-serveur.md` et ADR-008.
